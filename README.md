# أرشيف الصحف — محرّك بحث «أم القرى» و«صوت الحجاز»

بحث فوريّ في كل ما طُبع في صحيفتي **أم القرى** (1343–1405هـ / 1924–1985م) و**صوت الحجاز** (1350–1359هـ / 1932–1941م): **34,208 صفحات** و**7.18 مليون سطر** مفهرسة نصيًّا (SQLite FTS5) بإحداثيات كل سطر.

## المزايا
- **قائمة منسدلة فورية**: الكلمة في سياقها مظلَّلة، مع العدد والصفحة والتاريخ (الأقدم أولًا)
- **الموضع مصوَّرًا**: نقرة على النتيجة تعرض قصاصة العمود من صورة الأصل والسطر المطابق مظلَّل بالأصفر، مع رابط الصفحة كاملة
- **نسخ الخبر**: زر ينسخ نصّ أسطر القصاصة نفسها مذيَّلة بسطر توثيق (الصحيفة، العدد، الصفحة، التاريخ)
- **بحث مرن**: تطبيع الهمزات والتاء المربوطة والتشكيل؛ عبارة بين تنصيص للتلاصق؛ `OR` للبدائل
- **ترميم التواريخ**: تحليل سطر الترويسة الخام (أرقام شرقية/غربية بأي ترتيب)، تحويل هجري→ميلادي حسابي مُعايَر، واستيفاء سنة الأعداد غير المؤرَّخة بين جيرانها المؤرَّخين

## التشغيل
```bash
python3 server.py   # ثم افتح http://localhost:8017
```
المتطلبات: بايثون 3 مع Pillow (`pip install pillow`).

## البيانات (غير مرفوعة هنا)
يتوقع الخادم في **المجلد الأب**:
- `فهرس_الصحف.db` — فهرس SQLite (جداول `pages` و`lines` و`fts`) بحجم ~2GB
- مجلدات صور الصفحات بالمسارات المسجلة في عمود `pages.img`

النصوص من قراءة ضوئية (Apple Vision)، وصفحات الثلاثينيات كلها أُعيدت قراءتها بنموذج رؤية (Claude Opus) بدقة أعلى.

## الخطوط
الواجهة مصممة بخط **ثمانية** (font.thmanyah.com) وملفاته **غير مرفوعة** احترامًا لحقوقه — ضَع ملفات `woff2` في `خطوط/` إن كنت تملكها، وإلا سقطت الواجهة تلقائيًّا على خطوط النظام.
